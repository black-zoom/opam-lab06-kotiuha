## Завдання 3

Для генератора `Random(14)` створено 25 чисел у діапазоні [1; 7].

Початковий список:  
`1, 7, 4, 4, 4, 6, 2, 4, 5, 4, 5, 3, 2, 6, 6, 6, 6, 5, 1, 6, 5, 2, 3, 7, 1`

Результат без збереження порядку:  
`1, 7, 4, 6, 2, 5, 3`

Результат зі збереженням порядку:  
`1, 7, 4, 6, 2, 5, 3`

У цьому запуску результати мають однаковий порядок. Однак `HashSet` призначений для зберігання унікальних елементів, а не для збереження порядку, тому покладатися на порядок його елементів не слід. У другому способі список результату зберігає порядок першої появи чисел.

## Завдання 5

Заміри виконані в конфігурації Release на повних обсягах, зазначених у завданні. Загальний час запуску програми — близько 11 секунд; спискові операції не перевищили ліміт у 60 секунд.

### Висновки

1. На великих наборах словник і множина зазвичай швидші, бо пошук у списку потребує послідовного перегляду елементів.
2. На малих наборах різниця може бути непомітною. Точний поріг ці заміри не визначають; для невеликої кількості елементів список може бути достатнім.
3. За швидкість словник і множина потребують більше пам’яті та не гарантують порядку обходу елементів.
